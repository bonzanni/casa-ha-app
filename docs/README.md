# Casa — documentation for agents

> Code is the source of truth. This file is a map; when it and the code disagree, the code wins.

Canonical current-state reference for AI agents working on this repository. Written for an
agent that has just arrived and is about to change something.

Read [`doctrine/publishing.md`](doctrine/publishing.md) before writing anything here — this
repository is public, and everything published stays published. Then use the table below,
which is keyed on what you are about to do rather than on subsystem names.

Every document is ≤ 25 KB by design, so one fits in context beside the code it describes.
`llms.txt`, `doctrine/invariants.md`, the table above and each document's Source & test map
are generated from `manifest.yaml` — regenerate with
`python -m scripts.verify_docs . --write-nav` and never hand-edit them.

The rules a document follows, and which of them a machine actually checks, are in
[`contributing/doc-contract.md`](contributing/doc-contract.md).
